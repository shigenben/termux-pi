# Pi 原生 Termux 开发验收样例

这个独立小项目没有第三方依赖，使用 Node.js 自带的测试工具。无需执行 `npm install`。

## 原有行为

`src/elapsed.js` 导出 `formatElapsed(seconds)`，把非负有限数表示的时长格式化为 `分钟:秒`。两部分最少两位；分钟可以超过59。输入不是有限数时抛出 `TypeError`，负数时抛出 `RangeError`。

原有整数秒验收：

```sh
node --test --test-reporter=tap test/baseline.test.js
```

## 本次功能要求

增加**按最近整秒四舍五入**的行为，正好半秒时向上取整，同时保持原有整数、格式和输入检查行为。

例如：`0.49` → `00:00`，`0.5` → `00:01`，`12.6` → `00:13`，`59.6` → `01:00`，`119.5` → `02:00`，`3599.6` → `60:00`。

本次输入以这些测试覆盖的普通时长为范围，不涉及日期、时区、小时格式、文本解析或任意精度计算。

完整验收：

```sh
node --test --test-reporter=tap
```

## 修改范围

只修改 `src/elapsed.js`。不要修改测试、package.json 或本说明，不增加依赖，不访问其他项目、共享存储或用户凭据。当前样例目录约定是工作范围，不把这个文字约定称为操作系统隔离。

先实际运行测试并阅读失败，再修改代码，最后实际运行全部测试。最终说明执行了哪些命令、看到了哪些失败、修改了哪个文件和最终结果；没有执行过的动作不要写成已完成。
